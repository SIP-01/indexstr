## Preserve into v3 docs before archiving (unique to v1)

- **Deterministic sharding**: FNV-1a URL→shard, 256 shards, home shard derived from indexer pubkey; coordinator-free work split. (Code ported to v3; the design rationale is here.)
- **Kind 16919 heartbeat schema** and the "heartbeats are self-reported health, never a trust input" rule — important anti-gaming design note.
- **`src/crawler/sqlite.ts`** — a purpose-built minimal read-only SQLite parser (b-tree, records, overflow pages), no WASM. Genuinely unusual; worth keeping discoverable.
- **Blossom mirror pattern**: collection DBs shipped locally + content-addressed on `blossom.primal.net/<sha256>`, bytes always verified against the blob id — a clean supply-chain pattern for large static assets.
- **Enrichment layer**: deterministic, evidence-weighted topic classification (≤8 `t` tags) — "any node replaying the algorithm reproduces the tags, so classification agreement is verifiable."
- **Abuse guards**: per-indexer intake caps (Sybil guard), 150k queue ceiling, crawl-trap heuristics.
- **Network discovery intake**: nodes read *other* indexers' 39697 observations as discovery sensors.
